Stopwatch + hitung putaran

  1. Berdiri di garis start, tekan Mulai stopwatch, lalu simpan HP di saku. Layar boleh dimatikan.
  2. Hitung sendiri jumlah putaranmu selama berlari.
  3. Saat 12 menit habis, berhenti dan ingat titik berhentimu. Bunyi pengingat hanya terdengar bila layar sedang menyala, jadi pantau juga jam tanganmu.
  4. Nyalakan layar, lalu isi jumlah putaran penuh dan sisa jarak di putaran terakhir.

Jumlah putaran diisi sendiri, jadi hasilnya tercatat sebagai catatan mandiri, bukan terverifikasi.

Unggah file GPX dari Strava

  1. Rekam lari 12 menit dengan aplikasi Strava (versi gratis cukup). Layar boleh mati. Mulai rekam tepat di garis start; terlambat stop tidak masalah, SIGAP hanya menghitung 12 menit pertama.
  2. Buka strava.com di browser HP, lalu masuk ke akunmu.
  3. Aktifkan Situs desktop dari menu browser (titik tiga di Chrome, ikon "Aa" di Safari).
  4. Buka aktivitas lari tadi, ketuk menu ⋯, lalu pilih Ekspor GPX. File tersimpan di folder Unduhan.
  5. Kembali ke sini, lalu pilih file tersebut.

File diproses di HP-mu saja. Rute dan lokasimu tidak dikirim ke mana pun; yang disimpan hanya tanggal, jarak, dan nilai.

Layar HP harus tetap menyala selama lari

Browser berhenti menghitung GPS begitu layar mati atau kamu pindah ke aplikasi lain. Kalau itu terjadi, hasil tidak sah dan harus diulang.

  • Jangan tekan tombol power selama lari.
  • Jangan buka aplikasi lain, termasuk membalas WhatsApp.
  • Matikan mode hemat baterai, karena bisa mematikan GPS.
  • Pegang HP di tangan atau pakai armband. Boleh turunkan kecerahan layar supaya hemat baterai.
